# Employee Ownership Media History

The ChampEOns research file: every time employee ownership reached the public — 346 verified moments across 182 years of front pages, films, broadcasts and viral stories.

Built by Champions of Employee Ownership LLC. Produced by Fugio Consulting.

**The robots are coming. And we better own them.**

## Structure
- `index.html` — the site (generated, do not hand-edit)
- `data/entries.json` — the verified dataset (346 entries, news + culture tracks)
- `data/photos.json` — photo manifest (Wikimedia Commons / LOC, license-safe)
- `assets/img/` — downloaded photographs
- `build/build_site.py` — regenerates index.html: `python3 build/build_site.py`

Hosted on GitHub Pages.
